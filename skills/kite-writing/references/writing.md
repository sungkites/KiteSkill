# Writing modes / 写作模式

## Argument architecture

For a full original article, adapt rather than mechanically enforce this order:
problem and stakes → closest evidence and precise unresolved issue → method/mechanism
→ fair comparison and decisive tests → findings → interpretation and boundaries.

For each central claim, record a source result/figure/table or verified literature
passage. Keep planned results, observations and interpretations distinct. Section
length and citation count follow argument and venue, not fixed paragraph formulas.

## Translation and polishing invariants

Track meaning across revision: causal versus correlational language, observed versus
predicted behavior, significant versus meaningful difference, independent versus
repeated measurements, parameter units, denominators, confidence intervals and
reference identity. Reducing hedging is appropriate only when the evidence supports
the stronger statement. Never optimize text to evade AI detection.

Chinese planning can be direct and natural. English manuscript text should use a
consistent spelling convention selected by author/venue (British English when
explicitly requested). Prefer precise verbs and concrete scientific subjects over
promotional adjectives. Retain necessary technical terminology.

## Section-specific evidence

- Introduction: establish the problem and a defensible gap using closest work.
- Methods: explain assumptions, mechanism and enough detail for reproduction;
  move lengthy environment operations to supplementary material.
- Results: present the evidence answering the question; define units and uncertainty.
- Discussion: distinguish explanation, alternative explanations, scope and implication.
- Abstract: summarize only supported contributions and principal evidence; follow
  structured or unstructured format required by the venue.

## Output modes

Honor requested clean text, side-by-side translation, tracked changes or LaTeX.
If a file is requested, preserve equations, citations and cross-references and render
the result where supported. A successful compiler run does not prove the layout
or scientific statements are correct. State unperformed checks precisely.
