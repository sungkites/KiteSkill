# Project handoff / 项目交接

Create or update this record only when sustained work needs persistent context.
Read existing project instructions and outputs first. Store it with that project,
not inside the installed skill or this public repository. Respect an existing format.

```text
Research question / 研究问题:
Current claim and novelty boundary / 当前主张与创新边界:
Closest primary work / 最接近的原始文献:
Evidence available / 已有证据: identifier, artifact path, exact table/figure/passage
Evidence status / 证据状态: observed | inferred | hypothesized | missing
Completed work / 已完成:
Current task and scope / 当前任务与范围:
Critical unresolved dependency / 关键未解决依赖:
Resource and output constraints / 资源与输出约束:
Next action / 下一步:
```

Keep result claims out of a plan until supporting output exists. When a user
steers the work, update the relevant constraint while preserving the objective.
Use a supplied published paper as an organizational reference only; do not borrow
its claims, results, wording or contribution framing as if they were this project's.

If an optional module is absent, perform the fallback in SKILL.md and report which
specialized capability was unavailable. Do not stop just because a preferred skill
name is missing. Do not spawn a reviewer panel unless the user or applicable
instructions authorize delegation; multiple roles are not independent replication.
