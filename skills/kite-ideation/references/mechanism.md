# Mechanism worksheet / 机制贡献工作表

For each candidate, fill only what the evidence can support:

| Field | Question |
|---|---|
| Phenomenon | What measurable behavior is unexplained, and in what setting? |
| Mechanism | What process could cause it, beyond a descriptive correlation? |
| Prediction | What would change if this explanation were correct? |
| Rival | What alternative explanation makes a different prediction? |
| Intervention | Which variable can be changed without introducing the key confound? |
| Falsifier | Which result would reject or narrow the claim? |
| Novelty | Which nearest study does not already establish this, and why? |
| Feasibility | What is the smallest authentic-data/model pilot that discriminates? |
| Decision | Continue, narrow, pivot or abandon under each plausible outcome? |

For a new metric, show what information it identifies that established metrics
miss and why that matters for decisions; renaming an aggregation is insufficient.
For a new architecture, separate capacity, tuning, data and compute effects from
the proposed mechanism. Interpret the outcome within the design's precision and
scope rather than inventing an unsupported explanation.

Use the pilot's decision rule to choose the next informative experiment. A large
grid needs a scientific question and an explicit evaluation plan.
