# Kite Ideation / 研究构思与机制

Read [the mechanism worksheet](references/mechanism.md) when evaluating candidate
contributions or turning an observation into an experiment plan.

## From topic to a testable contribution

1. Extract the scientific object, setting, observed failure or unexplained
   phenomenon, and available data/compute. Reuse the user's existing context.
2. Find the closest primary studies and strongest credible alternatives using
   available scholarly search. Record what each actually established, assumptions,
   measured outcomes and unresolved boundaries. If live access is unavailable,
   label novelty assessment provisional and work from supplied papers.
3. Generate a small, diverse candidate set. Useful changes include breaking an
   assumption, distinguishing two causal mechanisms, resolving contradictory
   findings, predicting a failure boundary, or deriving an identifiable quantity.
   Do not force a fixed number if the evidence supports only one useful direction.
4. For each promising candidate, state a falsifiable explanatory or predictive
   claim, competing explanation, decisive comparison/intervention, expected
   falsifier, data needs and approximate cost. Distinguish a method idea from
   evidence that the method works.
5. Recommend the most informative feasible pilot. Explain why its outcome would
   change the research decision and how different outcomes guide the next action.

## Contribution judgment

Check novelty against the closest work, not only broad surveys. A module
combination or hyperparameter adjustment may be a useful baseline, but must earn
a scientific contribution through new explanation, prediction or demonstrated
capability in a justified setting. Avoid declaring a direction SCI Q1-ready from
its title, complexity, a model's score or the team's intent.

Keep comparisons fair: same information, data splits, tuning opportunity and
meaningful resource budget where relevant. A published number in a different
setting is contextual evidence, not a matched experimental win.

## Output

Provide a concise research memo with question, closest-work matrix, candidate
claim(s), novelty boundary, decisive pilot and explicit uncertainty. Chinese is
appropriate for planning unless the user requests English. Optional follow-up:
`kite-literature` for systematic source work or `kite-experiments` for execution;
if absent, include the search or experiment specification directly.
